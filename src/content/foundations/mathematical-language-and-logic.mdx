# Mathematical language and logic

This lesson introduces the idea that mathematics is a precise language. Definitions, statements and logic are the foundations for everything that comes later.

## Why this matters

Mathematics is not only about arithmetic. It is about making ideas clear enough that we can reason without ambiguity.

## The idea

A definition tells us what a word means. A statement can be true or false. A proof shows why a statement must be true.

## Worked example

We define an even number as an integer that can be written as $2k$ for some integer $k$.

Then $10 = 2\times 5$, so $10$ is even.

## Common mistake

A single example never proves a general claim. To show a statement is always true, we need a reason that works in every case.

## Guided practice

- Define an odd number.
- Decide whether every prime number is odd.
