# Addition and multiplication from first principles

We can define arithmetic precisely instead of treating it as a bag of memorised rules.

## Why this matters

The familiar rules of arithmetic come from a small set of recursive definitions.

## The idea

Addition is defined by $a + 0 = a$ and $a + S(b) = S(a+b)$.

Multiplication is defined by $a\cdot 0 = 0$ and $a\cdot S(b)=a\cdot b+a$.

These definitions lead to the familiar properties of number operations.
