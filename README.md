# MathsNode

MathsNode is a static mathematics learning platform for Foundations, National 4, National 5 and Higher.

## Scripts

- `npm install`
- `npm run validate`
- `npm run build`
- `npm run dev`

## Deployment

The site is configured for GitHub Pages with a custom domain of mathsnode.com through the Pages workflow in [.github/workflows/deploy.yml](.github/workflows/deploy.yml).
